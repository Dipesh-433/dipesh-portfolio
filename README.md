# Dipesh Shinde — Portfolio

A modern, responsive React portfolio focused on Quantum Computing, AI/ML, and software development.

## Stack

- React + Vite
- Framer Motion
- Lucide React
- Custom CSS
- Responsive design
- GitHub / LinkedIn / email links

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```

## Customize

Most personal content lives in:

```text
src/data/portfolio.js
```

Replace the LinkedIn placeholder there with your real profile URL.

## Add your photo

Put your image at:

```text
public/profile.jpg
```

The hero automatically uses it if present. Otherwise the UI displays a stylized initials placeholder.

## Deploy

This project can be deployed to Vercel, Netlify, GitHub Pages, Render, or any static hosting provider.
